Three ways to replace the current "pick a provider card, then scroll to a separate model panel" flow. All three use the live 35-model catalogue and real arithmetic, so the numbers move when you change the workload. Pick one and I will implement it.

One table, everything visible. Provider becomes a grouping band and a filter, not a separate click-through. Input and output cost sit side by side, each with a bar so the spread is readable without doing arithmetic. Sort by any column to answer "what is cheapest for my shape of workload".
