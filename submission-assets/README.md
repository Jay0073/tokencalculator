# TokenCalculator submission assets

This folder collects reusable assets for AI-tool directories, developer-tool
directories, social sharing, and product listings.

## Folders

- `logo/` — square TokenCalculator logo exports and the editable SVG source.
- `social/` — 1200×630 Open Graph/social thumbnail used when the homepage URL is shared.
- `screenshots/` — production app captures at desktop and mobile viewports.

The canonical homepage social image is `/public/social/token-calculator.png`.
Directory copies in this folder are provided for manual uploads and should not
replace the canonical site asset unless the design itself changes.
